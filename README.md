# ERP Inventory

ระบบจัดการสินค้า สต๊อก และบิลภาษาไทย เริ่มต้นด้วยข้อมูลว่าง ไม่มีสินค้า ราคา หรือบิลตัวอย่างในระบบจริง ข้อมูลและรูปเก็บในเบราว์เซอร์ของ origin นี้ ยังไม่มี backend, login หรือการซิงก์หลายเครื่อง

```powershell
npm.cmd install
npm.cmd run dev -- --port 5173
```

เปิด http://127.0.0.1:5173

- Inventory: เพิ่มหรือแก้สินค้าด้วยฟอร์มหน้าเดียว กรอกรหัสเองและเพิ่มประเภทได้ ชื่อ/สี/ไซซ์เดียวกันใช้รหัสเดียว แก้และลบทีละรหัส โดยไม่เปลี่ยนสต๊อก
- Stock management: รับเข้า (เขียว) จ่ายออก (แดง) ตรวจนับ และดูประวัติการเคลื่อนไหว
- ทำบิล: กดสินค้าใส่ตะกร้า → ดูสรุปแยก → ปรับจำนวน → ยืนยันและออกบิล สต๊อกเปลี่ยนเมื่อยืนยันเท่านั้น
- รายการขาย: เปิด แก้ ยกเลิก พิมพ์ หรือดาวน์โหลดภาพบิล

ลบสินค้าแล้วจะหายจากหน้าทำงานทันที โดยเก็บการอ้างอิงของสต๊อกและบิลเดิมไว้ การแก้บิลปรับสต๊อกตามผลต่างและการยกเลิกคืนฉบับล่าสุด ข้อมูลที่ผู้ใช้เพิ่มเองคงอยู่เมื่อโหลดหน้าใหม่ การล้างข้อมูลทดลองเดิมเกิดครั้งเดียวตาม marker ใน src/startup.ts

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run test:browser
node tests/simple-flow-browser.mjs
node tests/menu-separation-browser.mjs
node tests/empty-startup-browser.mjs
```

Browser tests ใช้ข้อมูลทดสอบใน context แยกจากผู้ใช้ ต้องเปิด server5173 ก่อน รองรับ CHROME_PATH และใช้ Edge ที่ติดตั้งใน Windows ผลตรวจและภาพอยู่ outputs/ ไม่มี route pitch หรือภาพสินค้า mock ที่ส่งไปกับระบบ

แบบหน้าจออ้างอิงระบบ eBay ตาม DESIGN.md พร้อมฟอนต์ไทยที่ self-host เอกสาร PRODUCT.md บันทึกขอบเขตและ flow ที่อนุมัติ ระบบป้องกันการเขียนทับ snapshot เก่า แต่ยังไม่รับรองธุรกรรมหลายแท็บพร้อมกัน

ดู Flow ทุกงานใน [FLOW.md](FLOW.md) และตรวจชุดใหม่ด้วย "node tests/admin-flow-browser.mjs"
