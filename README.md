# ระบบสต๊อกและบิลร้านขายส่งชุดชั้นใน — S4 Demo
## รุ่นปัจจุบัน
เพิ่มสินค้า/ประเภท/รุ่นและรูป พร้อม SKU สี/ไซซ์ที่เลือกใช้ได้ ยอดแยกแต่ละ SKU
หน้าสต๊อกเป็นการ์ด: งานที่เขียนบิลมือแล้วให้ใส่จำนวนและกดลดจำนวน (ไม่มีบิลในระบบ) พร้อมเลิกทำ ส่วนเมนูทำบิลเลือกสินค้าและจำนวนแล้วกดยืนยันในสรุปรายการเพื่อออกบิลและตัดยอดพร้อมกัน
บิลเงินสดตามreferenceแบบขาว–ดำ SVGและPNGใช้layoutเดียวกัน พิมพ์/บันทึกPDFผ่านเบราว์เซอร์ได้ รูปสินค้าเก็บในIndexedDBในเบราว์เซอร์เดิม
`npm.cmd run test:catalog` ตรวจรูป/สินค้า/บิล/stock shortcut เพิ่มจากชุดเดิม ข้อมูลv1ย้ายอัตโนมัติพร้อมเก็บkey `s4-demo-v1-backup` ก่อนเขียนv2 ไม่ล้างของเดิม
อ่าน outputs/S4-ui-update.md และ outputs/S4-test-checklist.md สำหรับขอบเขตและผลล่าสุด ข้อความcopyที่ผู้ใช้ให้นำออกถูกนำออกจากUI/ไฟล์บิล; ข้อเท็จจริงด้านprototypeและข้อมูลfixtureยังอยู่ในเอกสารทีม
ส่วนด้านล่างเป็นวิธีเปิดและบริบทเดิม (รายการร่างเดิมยังเปิดทำต่อได้ แต่ UIใหม่ไม่มีปุ่มสร้างร่าง)


เดโมข้อมูลและราคาจำลอง เบราว์เซอร์เครื่องเดียว ไม่มี backend/login/LINE API ข้อมูลเก็บใน localStorage ของ origin นี้ ไม่ซิงก์หลายเครื่อง

```powershell
npm.cmd install
npm.cmd run dev -- --port 5173
```

เปิด http://127.0.0.1:5173 เริ่มหน้าสินค้าได้เลย

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run test:browser
```

Browser test ต้องเปิด server 5173 อยู่ก่อน ใช้ Chrome ที่ติดตั้งใน Windows ถ้ามี หรือ Playwright Chromium (`npx.cmd playwright install chromium`) หากไม่มี กำหนด CHROME_PATH เพื่อเลือก executable อื่นได้ ผลอยู่ outputs/S4-browser-results.json และภาพใน outputs/ ส่วน /pitch เป็น layout S4 ใช้ภาพเดโมจริงที่สร้างจาก browser test

สินค้า → เลือกขาย DEMO-A → จำนวน 3 → ตรวจรายการ → ยืนยัน → เหลือ 9 แพ็ก บิล 540 บาท → ดาวน์โหลดภาพบิลและส่งเองผ่าน LINE
ร่างไม่ตัด ยืนยันซ้ำไม่ตัดซ้ำ แก้บิลปรับผลต่าง ยกเลิกคืนฉบับล่าสุด ไม่แปลงหน่วย

รีเซ็ตข้อมูลสาธิตต้องยืนยัน ล้างเฉพาะ key s4-demo-v1 และคืน seed
ระบบใช้ข้อมูลหนึ่งแท็บเป็นหลัก ไม่ใช่ระบบใช้งานร่วมกัน ตัวป้องกัน snapshot เก่าช่วยหลีกเลี่ยงการเขียนทับตามลำดับ แต่ไม่รับรองธุรกรรมหลายแท็บพร้อมกัน
