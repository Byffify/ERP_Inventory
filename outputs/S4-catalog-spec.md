# เพิ่มรูป รุ่น และ SKU — brief ที่อนุมัติ
ประเภท → รุ่นสินค้า (ชื่อ/รายละเอียด/รูปหลัก) → SKU (สี/ไซซ์แบบไม่บังคับ รหัสเฉพาะ หน่วย ราคา ยอดแยกกัน และรูปเฉพาะเมื่อจำเป็น)
Mobile first 320px ใช้ Design System เดิม ไม่มี backend/หลายเครื่อง
เพิ่มสินค้า → ข้อมูลรุ่นและรูป → เสนอชุดสี/ไซซ์ให้เลือกเฉพาะที่ขายจริง → ตรวจและบันทึก
ไม่มีสี/ไซซ์ก็มี SKU เดียวได้ รูปเฉพาะใช้แทนรูปหลัก; ไม่มีรูปเฉพาะใช้รูปหลัก
อัปโหลด JPEG/PNG/WebP จากอุปกรณ์ ย่อก่อนเก็บใน IndexedDB รูปไม่อยู่ใน localStorage metadata ยังเป็น snapshot เดียว รูปที่อัปโหลดแต่ไม่ได้บันทึกถูกล้างเมื่อออกจากฟอร์ม
รุ่นใหม่แต่ละ SKU มียอดตั้งต้นผ่าน movement ประเภท opening ราคาเป็นสตางค์ บังคับรหัสไม่ซ้ำและชุดสี/ไซซ์ไม่ซ้ำในรุ่นเดียวกัน
SKU ที่มีของตั้งต้นมากกว่า0/รับเข้า/ขาย/ถูกอ้างในบิลแล้วล็อกหน่วย สี ไซซ์และรหัส; ปรับราคา รูป ชื่อรุ่นและประเภทได้ ปิดใช้งานแทนลบ เก็บประวัติและรองรับการคืนจากบิลเดิม
ย้าย snapshot v1→v2 โดยเก็บรหัสสินค้า stock movements sales/history เดิม พร้อม backup raw ก่อนเขียน v2 การย้ายล้มเหลวไม่ทับข้อมูลเดิม
ตรวจรูปหลังรีโหลด การเลือกแต่ละ SKU ตัดยอดแยก การแก้ catalog ไม่เปลี่ยนบิลเก่า การปิด SKU ไม่ทำประวัติหาย และ responsive/accessibility
