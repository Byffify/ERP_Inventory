# Inventory — layout ตามภาพอ้างอิง

ปรับจากภาพที่ผู้ใช้แนบ โดยใช้สี ivory/slate ฟอนต์ Noto Sans Thai และ spacing/radius ตาม Design System เดิม ไม่มี gradient/shadow หรือสีเขียว/แดง/เหลืองจากภาพ

- ลำดับการอ่าน: รูปและรหัส/ชื่อ/สีไซซ์/ประเภท → คงเหลือและสถานะ → รับเข้า/ลดจำนวน
- แสดงยอดต่อ SKU ตัวเลข32px หน่วย18px ปุ่ม48px+ ชื่อ20px การ์ด16px paddingบนมือถือ และ24pxบน desktop
- ช่องจำนวนเปิดเฉพาะเมื่อเลือกลดจำนวน ได้ focus ทันที การปิด/เปลี่ยนตัวกรองคืนค่าจำนวนเป็น1 ลดจำนวนยังไม่สร้างบิลและมีundoเดิม
- ค้นหาชื่อ รุ่นหรือรหัส ปุ่มประเภทเปิดตัวกรองประเภทสินค้า ชิปทั้งหมด/มีสินค้า/หมดใช้กรองสถานะสต๊อกแยกกัน
- ประเภทมาจาก Category ของรุ่น ไม่ใช้คำว่าหมด/มีสินค้าเป็นประเภท
- สถานะมาจากยอด SKU: 0=หมด มากกว่า0=มีสินค้า อัปเดตหลังรับเข้า/ขาย/ลดเอง/undo ไม่เก็บ flagที่อาจขัดกับยอดจริง
- หมดแล้วปุ่มลดจำนวน disabled แต่รับเข้าได้ ยังแยกปิดใช้งานออกจากยอดสต๊อก
- ข้อความสำเร็จและปุ่มเลิกทำติดด้านบนเมื่อใช้งานการ์ดท้ายรายการ ตรวจแล้วว่าเลิกทำอยู่ในviewportและคืนยอดได้
- ไม่เติมเกณฑ์ใกล้หมดหรือชั้น/โซนจากภาพ เนื่องจากยังไม่มีข้อมูลดังกล่าว
