# S4 — ขอบเขตล่าสุดที่สร้างและตรวจ

## สต๊อกและสินค้า
- เพิ่มประเภท รุ่น รูปหลัก และ SKU สี/ไซซ์แบบไม่บังคับ ราคา หน่วยและยอดตั้งต้นแยกกัน เลือกสร้างเฉพาะชุดที่ขายจริง
- รูป JPEG/PNG/WebP จากอุปกรณ์ เก็บเป็น blob ใน IndexedDB ย่อด้านยาวไม่เกิน1200px รูปเฉพาะ SKU ใช้แทนรูปหลัก รูปยังอยู่หลังรีโหลด
- หน้าสต๊อกเป็นการ์ด ยอดตัวใหญ่ รับเข้าและลดจำนวนตรงการ์ด มีเลิกทำรายการลดจำนวนล่าสุด
- ลดจำนวนสำหรับงานที่เขียนบิลมือแล้ว ไม่สร้างใบขายในระบบ การกดทำบิลเป็นอีกเส้นทางและตัดยอดเมื่อยืนยัน
- รายการลดจำนวนมีประวัติและ idempotency; เลิกทำคืนครั้งเดียว; ไม่ให้ยอดติดลบหรือการลดที่บันทึกล้มเหลวเปลี่ยนยอด
- รุ่น/SKU เดิมย้ายโครงสร้าง v1→v2 โดยคง IDs ยอด บิลและประวัติ เก็บ raw backup ก่อนเขียนข้อมูลใหม่
- SKU มีรายการแล้วล็อกสี ไซซ์ หน่วยและรหัส ปิดใช้งานแทนลบ บิลเดิมไม่เปลี่ยนตามการแก้ชื่อ/ราคา

## งานขาย
- เลือกสินค้าและจำนวน เห็นสรุปในหน้าเดียว ไม่มีบันทึกร่างและไม่มีหน้าตรวจรายการแยก
- ปุ่มยืนยันและออกบิลอยู่ใน “สรุปรายการ” ไม่มีแถบยอดรวมด้านล่าง
- ร่างจากรุ่นเก่ายังเปิดทำต่อได้ ยืนยันบิลกับสต๊อกเป็น snapshot เดียว แก้ปรับผลต่างและยกเลิกคืนฉบับล่าสุด

## บิล
- ใช้ reference เฉพาะแบบฟอร์มกระดาษ ไม่ใช้กรอบโปสเตอร์หรือข้อความรับรองจากภาพ
- พื้นขาว หมึก slate/ดำ พื้นช่องกรอกและตารางสีอ่อนตาม DS; เล่ม/เลขที่ ช่องข้อมูลร้านพร้อมมุมเส้น L, แถบ “บิลเงินสด / CASH SALE”, นาม/วันที่/ที่อยู่/ทะเบียนการค้า, ตาราง Quantity/Description/Unit Price/Amount, บาท/รวมเงิน, ผู้รับเงิน
- SVG บนจอและ PNG ใช้ receipt-layout.ts ชุดเดียวกัน ตำแหน่งช่องและตารางตรงกัน รองรับข้อความยาวโดยเพิ่มความสูง ไม่ตัดข้อมูล
- พิมพ์/บันทึก PDF ผ่านหน้าพิมพ์ ใช้บิลที่บันทึกแล้ว ไม่ตัดยอดเพิ่ม ช่องผู้รับเงินไม่สร้างลายเซ็นให้เอง
- นำข้อความจำลอง/สาธิต/ต้นแบบและข้อกำกับภาษีที่ผู้ใช้ระบุออกจาก UI และไฟล์บิล ชื่อบิลเป็นบิลเงินสดตามคำขอล่าสุด

## ขอบเขตที่ยังคงเดิม
การนำข้อความออกเป็นการเปลี่ยน copy ไม่ใช่หลักฐาน production readiness การรับรองเอกสารทางภาษี หรือผลทดสอบร้านจริง
ยังเป็นระบบในเบราว์เซอร์เดียว รูปไม่ได้ขึ้น cloud ไม่มีหลายเครื่อง/บัญชี/LINE API/ชำระเงินออนไลน์ ไม่มีข้ออ้างผลลดเวลา ยอดขายหรือ willingness to pay
ข้อมูลตั้งต้น A/B/C และราคามาจาก fixture เดิม ไม่ใช่ข้อมูลสัมภาษณ์ร้าน งานนี้ไม่มีหลักฐานว่าร้านใช้งานจริงแล้ว
