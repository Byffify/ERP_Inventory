# S4 — เนื้อหาพร้อมใช้
## ฉบับปรับตาม flow ล่าสุด
หัวข้อ: **เห็นยอดชัด ขายแล้วปรับสต๊อกได้**
Flow: เลือกสินค้า → สรุปยอด → ออกบิล
ภาพหลัก: S4-main-screen.png (จากระบบจริง); ภาพสต๊อกล่าสุด S4-stock-cards-mobile.png และ S4-stock-cards-desktop.png
ภาพบิล: S4-paper-bill.png; PDFจากหน้าพิมพ์: S4-paper-bill.pdf
สคริปต์เป้าหมาย25วินาที: “หน้าสต๊อกแสดงยอดแยกสีและไซซ์ครับ ถ้าเขียนบิลมือแล้ว กดลดจำนวนได้โดยไม่ต้องทำบิลซ้ำ ส่วนการขายผ่านระบบ เลือกสินค้า ใส่จำนวน แล้วกดยืนยันในสรุปรายการ ระบบตัดยอดพร้อมออกบิลเงินสด ดาวน์โหลดภาพหรือพิมพ์ได้ และรับของเข้าเพื่อเพิ่มยอดได้ครับ”
ยังไม่ได้จับเวลาคนพูดจริง; ข้อมูลตั้งต้นในภาพเป็น fixture ไม่ใช่ข้อมูลร้านจริง ไม่อ้างผลประหยัดเวลาหรือการใช้งานจากร้าน
ข้อความและ flow รอบแรกด้านล่างเก็บเป็นประวัติ ไม่ใช้คำว่าร่างในสไลด์ล่าสุด

หัวข้อ: **ตรวจยอด ทำบิล ยืนยันแล้วตัดสต๊อก**
Flow: ตรวจสินค้า → ตรวจบิล → ยืนยันขาย
ตัวอย่าง: **12 แพ็ก − ขาย 3 แพ็ก = คงเหลือ 9 แพ็ก**
กำกับ: ข้อมูลจำลอง • ยอดขึ้นกับการบันทึกเข้า–ออกครบ

## สคริปต์เป้าหมาย 25 วินาที
“MVP นี้ให้ร้านตรวจยอด เลือกสินค้า และตรวจบิลก่อนยืนยันครับ ร่างยังไม่ตัดสต๊อก ยืนยันแล้วจึงลดจำนวน เช่น ข้อมูลจำลองนี้มี 12 แพ็ก ขาย 3 เหลือ 9 พร้อมบิลขายตัวอย่างให้คนส่งผ่าน LINE เอง และบันทึกรับของเข้าได้ ยอดยังขึ้นกับการบันทึกเข้าออกครบครับ”

สถานะเวลา: ยังไม่ได้จับเวลาคนพูดจริง ห้ามรายงานว่าผ่าน 25 วินาทีแล้ว

## เปิดและสาธิต
ติดตั้ง: npm.cmd install
เปิด: npm.cmd run dev -- --port 5173
ใช้ URL ที่ terminal แสดง เปิดหน้าสินค้าโดยไม่มี login; รีเซ็ต seed ก่อนเริ่ม
0–5 วินาที: ยอด A 12 แพ็ก; 5–12: เลือกขาย 3 และตรวจบิล; 12–18: ยืนยัน ยอด 9 บิล 540; 18–25: ชี้ดาวน์โหลดและรับเข้า
ตรวจรับเข้า แก้ ยกเลิก และส่ง LINE แยกนอกช่วง pitch ใช้ภาพหลักสำรองหากเดโมสดไม่พร้อม

## Layout
16:9 พื้น #000000 ข้อความ #faf9f5 หัวข้อ 40pt เนื้อหา 26pt กำกับ 16pt ใช้ Noto Serif Thai regular และ Noto Sans Thai ภาพหน้าจอมือถือจริงเพียงภาพเดียว ไม่มี device frame หรือ top-nav/footer เพิ่มลงสไลด์
